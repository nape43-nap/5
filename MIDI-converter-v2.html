🎵 MIDI → ノーツ変換ルール
白鍵の音名 → レーン
C → レーン0
D → レーン1
E → レーン2
F → レーン3
G → レーン4

音域 → ノーツ種類
C3〜G3 → TAP / LONG
C4〜G4 → FLICK
C5〜G5 → SLIDE

LONG
MIDIノートの長さが 0.25秒以上 ならLONGになります。

SLIDE
近い時間に並んだC5〜G5を 自動的に1本のSLIDEへ結合します。
例：
C5 → D5 → E5 → F5 → G5
↓
path: [0,1,2,3,4]

同時押し
同じ時刻のMIDIノートは そのまま同時押しとして出力されます。
🎢 SLIDE自動結合設定
この秒数以内に次のSLIDEノートがあれば、 同じSLIDEとして結合します。
例：0.6秒なら
C5 10.0秒 → D5 10.2秒 → E5 10.4秒
は1本のSLIDEになります。
